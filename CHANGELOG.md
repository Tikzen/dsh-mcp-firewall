# Changelog

## 0.6.0

- Added configurable approval timeout: on/off control and a 1-minute to 7-day duration.
- Recalculate existing pending approvals immediately when the timeout policy changes.
- Record automatic timeout rejections separately from manual decisions.
- Added a complete GitHub-facing README with installation, safety boundaries, screenshots, and workflow documentation.

## 0.5.0

- Added session-scoped target grants, policy simulation, policy conflict detection, and safe repair.
- Added per-conversation call chains, approval controls, local AI analysis fallback, and responsive resizable panels.
- Excluded safety-demo activity from real metrics and exported reports.
